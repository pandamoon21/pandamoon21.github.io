# pandamoon21.github.io

GitHub Pages site used as the homepage and privacy-policy host for the
**EnigamiBot rclone** OAuth application.

- `index.html` — homepage, names the app "EnigamiBot rclone", links to the
  privacy policy.
- `privacy.html` — privacy policy.

URLs registered in the Google Cloud OAuth consent screen:

- Homepage: `https://pandamoon21.github.io`
- Privacy policy: `https://pandamoon21.github.io/privacy.html`
- Authorized domain: `github.io`
