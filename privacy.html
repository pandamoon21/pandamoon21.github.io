Privacy Policy

EnigamiBot rclone — last updated 2 October 2026

This policy covers the EnigamiBot rclone OAuth application and the privately operated bot that uses it. The application is used by a single person, its owner, to upload files to that same person's own Google Drive account.

What is collected

Nothing is collected. The application does not gather, profile, log, or retain any personal information about anyone. It has exactly one user, and that user is the owner of the Google Drive it writes to.

How Google Drive data is used

  • The application requests the https://www.googleapis.com/auth/drive scope solely to create files in the owner's own Google Drive.
  • It does not read, list, modify, or delete Drive content beyond the folder the owner directs it to.
  • No Drive content is transmitted to the developer, to any third party, or to any analytics or advertising service.

Storage of credentials

OAuth credentials and the resulting refresh token are stored locally on the owner's own server, in a file readable only by that server's account. They are never sent anywhere except to Google's own OAuth and Drive API endpoints.

Sharing

No data is shared, sold, rented, or disclosed to anyone. There is no third party involved.

Retention and deletion

Because nothing is collected, there is nothing to retain. The owner can revoke the application's access at any time at myaccount.google.com/permissions, which immediately invalidates the stored token.

Children

The application is not directed at children and is not used by anyone other than its owner.

Changes

Any change to this policy will be published on this page with an updated date at the top.

Contact

The owner can be reached through the GitHub profile that hosts this page.
