EnigamiBot rclone

Personal Google Drive Uploader

EnigamiBot rclone is a private, self-hosted Telegram bot that uploads files to its owner's own Google Drive account using rclone. An OAuth client is registered under this name so the bot can authenticate to the Google Drive API with its own API quota rather than a shared one.

What it does

  • Receives a download request through Telegram from its single owner.
  • Fetches the file and uploads it to the owner's personal Google Drive.
  • Stores the resulting file in a folder the owner controls.

Who uses it

One person — the owner. The application is not distributed, not published to any app store, and has no other users.

Data

The bot accesses only the owner's own Google Drive. It does not read, collect, or transmit Drive contents anywhere else. See the Privacy Policy for details.
